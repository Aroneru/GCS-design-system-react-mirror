# Teaching Notes

## Learner preferences
- Language: **English** for lessons, quizzes, references.
- Format: short lessons, one tangible win each. Keep within working memory.
- Level: some React experience (components, props, `useState`/`useEffect`).
  New to design-system-grade component craft.
- Goal is **deep understanding** — always teach the *why* from first principles,
  not just the pattern. Back claims with citations to trusted sources.

## Repo context
- `design-system-react`: React 19 + TypeScript + Vite starter, minimal.
- No CSS framework installed. `src/` is still the Vite template (`App.tsx` etc.).
- Teaching workspace lives at the project root (MISSION.md, lessons/, etc.).

## Teaching decisions
- Lesson 1 focuses on the **props API mindset shift** (variant/size over booleans),
  the highest-leverage first skill for this mission.
